# TechHaven – E-Commerce Electronics

A modern and responsive electronics e-commerce frontend built using React and custom external CSS.  
This project focuses on clean UI design, smooth user experience, and responsive layouts for all devices.

## 🚀 Features
- Responsive Design
- Product Listings
- Modern UI/UX
- Shopping Cart Interface
- Category Sections
- Fast Performance
- Reusable React Components

## 🛠️ Technologies Used
- React.js
- JavaScript (ES6)
- HTML5
- External CSS
- Vite
